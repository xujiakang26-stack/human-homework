# 人类写作业 human-homework

一个面向大学课堂作业和实验报告的 Agent Skill。用户一次提供题目、课件、代码、数据及参考作业，Agent先检查材料并及时提问对齐，再利用当前电脑已有环境实际完成操作，整理可提交的文件。

主要约定：

- 只读本次作业相关材料，有必要缺口再集中询问；沿用已确认要求
- 优先使用本机已有软件和依赖，不默认有管理员权限或联网能力
- 下载、环境和辅助文件集中在课程准备目录，方便后续清理
- 在指定软件中真实运行，截图来自实际操作，结果可核对
- 文档宋体小四（12磅），题号和标题同字号，截图保留软件原字体
- 多截图、少文字，表达自然，不加图号、无关说明、封面、目录或页码
- 每段末尾去掉句号，全文最后一句末尾不加标点，不额外写总结段
- 只交一份 PDF 或 Word 报告和题目要求修改、完成的文件；保留必要依赖，不默认附 JAR、脚本、环境或压缩包
- 报告用“姓名_学号_作业N”或“姓名_学号_日期”命名，提交目录默认放在课程根目录的 `00_作业N提交`
- 有效结果直接复用，换电脑或会话先读取进度，不重复搭建环境或重跑实验
- 新报告逐页查看一次，后续只检查改动影响的部分；完成一次必要核对后直接交付

完整规则见 [SKILL.md](SKILL.md)。老师指定的格式和必交内容优先于个人排版偏好；不固定页数、软件品牌或编程语言。

## 使用

把这个仓库作为名为 `human-homework` 的技能目录放入支持 Agent Skills 的工具所使用的技能位置。对于使用个人技能目录的 Codex，可将仓库克隆到 `~/.codex/skills/human-homework`；若该目录已存在，请先保留本地修改，再合并更新，勿直接覆盖。

示例请求：

> 使用 $human-homework 完成这次作业。先读本次题目和相关材料，必要问题集中问我，复用已有环境和结果，真实完成必做实验与截图。按我的朴素报告格式整理，只做一次必要核对，修改后只查受影响部分，最后给我根目录的提交文件夹和最新文件链接。

需要Agent具备相应的本地文件、执行和软件操作能力。技能本身不附带软件、Python环境、宋体字体或数据，也不会自动获取管理员权限。学校电脑存在权限或依赖限制时，应先对齐处理方式。

“可直接提交”是文件准备完成，不会自动代表用户上传教学平台。仓库只包含技能规则与使用说明，不包含实际课程材料或个人作业
